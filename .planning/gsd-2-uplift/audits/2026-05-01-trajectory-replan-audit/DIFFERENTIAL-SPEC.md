# Differential calibration — codex AUDIT-SPEC.md vs Claude-parallel-skeleton

This document analyzes the differential between codex's independent AUDIT-SPEC.md draft and Claude's parallel-skeleton (authored blind to codex). The differential is **diagnostic of Claude framing-inheritance**, not a list of "what codex got right." Both artifacts are inputs to Logan's spec-disposition decision.

**Topline read.** Codex's spec is materially stronger than Claude's parallel-skeleton on multiple structural dimensions. The strength differential confirms B-strong's structural-independence purpose worked: codex saw from outside the 2026-05-01 turn-cluster what Claude couldn't see from inside. Claude-skeleton over-anchored on specific concerns the recent conversation produced (closure-pressure-pattern; framing-inheritance-risk-recursion) and under-anchored on operational-rigor mechanisms + several specific framing biases.

## §1. Convergent decisions (both drafts agree)

These represent **joint findings** about what the audit needs:

1. **Recursive failure-mode catch as load-bearing.** Both specs treat audit-spec-itself-at-framing-inheritance-risk per 2026-04-30 §5.3 as the central concern.
2. **Mapping-shape itself auditable, not presumed correct.** Both specs allow Class C findings even if they restart the trajectory-replan cycle.
3. **12-property substrate-vision + C1/C2/C3/C4 model are imported inputs, not observed facts.** Both apply §7.1 reading-frame discipline.
4. **Paired discipline default + Logan-discretion downgrade.** Both specs preserve the §2.3 paired-default + Logan-disposable downgrade form.
5. **Self-review (concerns 2-5 applied) is itself under audit** — both treat the self-review trace as artifact-at-risk per the plan's own final caveat.
6. **AUDIT-SPEC v2 precedent followed for output structure** (FINDINGS / FINDINGS-STEP2 / DIFFERENTIAL / DISPOSITION).
7. **Forbidden inputs include the running conversation** (transcript, runtime mirrors, runtime memory).
8. **Lens question categories Q-SF / Q-FI / Q-MM / Q-PF / Q-PG / Q-AD / Q-NS / Q-Meta** (codex sometimes labels as Q-PD / Q-PE distinctly).

Convergence on (1)-(8) is M1 paired-review confirmation: these are vendor-position-symmetric concerns; both drafts independently identified them as required.

## §2. Codex-only structural additions (Claude-skeleton missed)

These are mechanisms codex included that Claude-skeleton did NOT include. Each is a **diagnostic of Claude over-anchoring on conversation-immediate concerns at the expense of operational-rigor mechanisms.**

### §2.1 Evidence-type discipline (codex §2.5)

Codex requires every finding to label strongest evidence: source-traceable / artifact-reported / derived / interpretive / stipulative-input-frame. **Claude-skeleton had no equivalent.**

Why this matters: without evidence-type labels, derived/interpretive claims can be stated as if source-traceable. The 2026-04-30 §5.1 closure-pressure-pattern specifically produces interpretive-claims-as-fact; the audit needs to catch this at the finding level. Codex saw this; Claude didn't.

**Disposition signal:** integrate codex's §2.5 into final spec. Strengthens the audit's resistance to the failure mode it's trying to catch.

### §2.2 Forbidden-reading list including SPEC-DRAFTING-BRIEF.md (codex §2.4)

Codex explicitly forbids auditors from reading SPEC-DRAFTING-BRIEF.md unless Logan asks for spec-provenance check. **Claude-skeleton had no equivalent.**

Why this matters: the brief is Claude-authored; auditor-reading-the-brief re-imports Claude framing. Codex's spec carries lens-questions directly (§4) so auditors don't need to re-read the brief. Claude implicitly assumed brief-readable; codex explicitly broke that chain.

**Disposition signal:** integrate codex's §2.4 forbidden-reading list. Aligns audit-execution with B-strong's structural-independence purpose.

### §2.3 Output line-target constraints (codex §6.5)

Codex specifies Step 1: 250-600 lines; Step 2: 250-600 lines; Differential: 150-350 lines. **Claude-skeleton had no equivalent.**

Why this matters: line targets discipline against both under-investigation (audit too short) and elaboration-as-comfort-language (audit too long with diluted findings). Codex's targets are calibrated against Phase A precedent (~600 lines).

**Disposition signal:** integrate codex's §6.5 line targets.

### §2.4 Confidence-level taxonomy (codex §5.4)

Codex requires findings to record High / Medium-high / Medium / Low confidence. **Claude-skeleton had no equivalent.**

Why this matters: without confidence calibration, the audit can produce uniformly-confident findings that papers over real uncertainty. Per §0.6 false-confidence-calibration failure mode, this is exactly what the audit needs to surface.

**Disposition signal:** integrate codex's §5.4 confidence levels.

### §2.5 Finding-type taxonomy (codex §5.3)

Codex specifies 14 finding-types (question-shape / methodology-fit / framing-inheritance / integration-grammar-as-fact / performative-openness / closure-pressure / negative-space / phase-gate-semantics / artifact-custody / audit-discipline / evidence-type-confusion / scope-creep / register/comfort-language / inverse-signal). **Claude-skeleton had no equivalent.**

Why this matters: typed findings allow Logan to disposition by-pattern rather than by-finding. Cross-cutting patterns (e.g., 5 framing-inheritance findings across phases) signal systemic vs. local issues.

**Disposition signal:** integrate codex's §5.3 finding-type taxonomy. Includes the "inverse-signal" category which Claude-skeleton entirely missed (where the plan resists the failure mode + where mapping discipline appears operational).

### §2.6 Sensitivity check at Phase E (codex Q-PE-5)

Codex asks: "which one category, property, or intent would change the readiness outcome if reclassified?" **Claude-skeleton had no equivalent for sensitivity-of-readiness-outcome.**

Why this matters: Phase F gate criterion 1 (mapping-coherent) + criterion 2 (≥1 C1 path) can be technically met while substantively unsupported if a single classification is fragile. Sensitivity check is foundation-audit-METHODOLOGY discipline; Claude-skeleton missed it because Claude-skeleton over-anchored on Phase D-shape concerns rather than Phase E/F gate-fragility.

**Disposition signal:** integrate codex's Q-PE-5.

### §2.7 Re-audit trigger explicit list (codex §7.4)

Codex specifies 6 conditions that require re-audit (mapping replaced; gate semantics change; downgrade rule changes; 12-property/C1-C4 model authority changes; artifact custody changes; spec mis-scoped). **Claude-skeleton had no equivalent.**

**Disposition signal:** integrate codex's §7.4.

### §2.8 Differential-method authority to preserve disagreement (codex §3.5)

Codex's §3.5 explicitly: "The differential should not force consensus. It should preserve the disagreement." Claude-skeleton said "preserve real disagreement" but did not give the differential explicit authority. Codex's framing is sharper.

**Disposition signal:** integrate codex's §3.5 wording; specifically the partition of joint / cross-vendor-only / same-vendor-only / classification-disagreements / method-disagreements.

## §3. Codex-only lens-question additions (Claude-skeleton missed)
